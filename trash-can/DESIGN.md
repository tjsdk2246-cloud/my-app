# DESIGN — 경영지표 분석·보고 챗봇 (PLAN.md 기반)

## 1. 화면 구성 (무엇이 어디에 보이는지)

**① 로그인 화면**
- 화면 중앙에 공용 비밀번호 입력칸 1개와 "확인" 버튼만 있다.
- 비밀번호가 틀리면 화면 안에 안내 문구가 뜬다.

**② 업로드 화면**
- 지표별(환자 수, 매출액, 진료과 실적, 수술 실적, 병상가동률) 엑셀 파일을 여러 개 선택하는 영역이 있다.
- 파일을 고르면 목록에 파일명이 나열되고, "업로드" 버튼을 누르면 리포트 화면으로 넘어간다.

**③ 리포트 화면**
- 위쪽에 KPI 카드가 지표별로 하나씩 나열된다. 카드마다 이번 달 수치, 전월 대비·전년 대비 증감률이 함께 보인다.
- 전월 또는 전년 대비 ±10% 이상 변동한 카드는 색을 다르게(예: 눈에 띄는 색 강조) 표시해 이상 징후임을 알린다.
- 화면 위쪽에 "PDF로 다운로드" 버튼이 있다.
- 화면 아래쪽에 챗봇에게 궁금한 점을 물어보는 대화창이 있다. (nice to have)

## 2. 데이터 흐름 (입력 → 처리 → 출력)

1. **입력**: 사용자가 지표별 엑셀 파일 여러 개를 업로드한다.
2. **처리**:
   - 서버가 엑셀 파일들을 읽어 지표별 값만 뽑아낸다.
   - 이번 달 값을 저장소에 저장한다.
   - 저장소에서 지난달·작년 같은 달 값을 찾아와 증감률을 계산한다.
   - 증감률이 ±10% 이상인 지표를 이상 징후로 표시한다.
3. **출력**: 화면에 KPI 리포트(카드 + 이상 징후 표시)가 나오고, 원하면 PDF로 내려받을 수 있다. 챗봇에게 물으면 저장된 데이터를 근거로 답한다.

## 3. 기술 선택

- **Next.js (App Router)** — 화면과 서버 코드를 한 프로젝트에서 같이 다룰 수 있는 기본 도구. Part 5에서 Vercel로 그대로 배포한다.
- **엑셀 읽기 라이브러리 (xlsx)** — 엑셀 파일 내용을 컴퓨터가 계산할 수 있는 표 데이터로 바꿔주는 도구.
- **데이터 저장소 (Supabase)** — 업로드한 숫자를 다음 달·다음 해 비교를 위해 보관해두는 온라인 창고. `.env`에 이미 접속 정보(SUPABASE_ACCESS_TOKEN)가 있어서 바로 연결할 수 있다.
- **PDF 생성 라이브러리** — 화면에 보이는 리포트를 그대로 PDF 파일로 바꿔주는 도구.
- **비밀번호 보호 기능** — 별도 프로그램 설치 없이 Next.js 자체 기능으로, 정해진 비밀번호를 입력해야만 화면이 보이게 막아주는 장치.
- **OpenAI API (nice to have)** — 업로드된 데이터를 근거로 사용자의 질문에 답해주는 AI. `.env`에 이미 키(OPENAI_API_KEY)가 있다.
