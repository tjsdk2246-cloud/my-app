# PLAN — 경영지표 분석·보고 챗봇 (PRD.md 기반)

## 이번 사이클 목표

PRD.md에 정의된 경영지표 분석·보고 챗봇의 핵심 기능(엑셀 업로드 기반 KPI 리포트 자동 생성, 전월·전년 대비 이상 징후 탐지)을 구현해 실제로 동작하는 MVP를 완성한다.

## 성공 기준

- [ ] 지표별 엑셀 파일 여러 개를 업로드하면 화면에 KPI 리포트가 생성된다.
- [ ] 전월 대비 또는 전년 동월 대비 하나라도 ±10% 이상 변동한 지표가 이상 징후로 표시된다.
- [ ] 리포트를 화면에서 확인하고 PDF로 다운로드할 수 있다.
- [ ] 업로드한 데이터가 서버에 저장되어 다음 달 비교에 쓰인다.
- [ ] 공용 비밀번호 없이는 화면에 접근할 수 없다.
- [ ] `npm run lint`, `npm run build`가 오류 없이 통과한다.

## 작업 목록 (만들 순서대로)

1. 공용 비밀번호로 전체 화면을 보호하는 인증 미들웨어와 로그인 화면을 만든다.
2. 엑셀 파싱 라이브러리를 설치하고, 엑셀 파일을 서버로 업로드받는 API 라우트를 만든다.
3. 업로드된 엑셀에서 정해진 KPI 항목(환자 수·매출액·진료과 실적·수술 실적·병상가동률)만 추출하는 파싱 함수를 만든다.
4. 파싱한 데이터를 저장할 데이터 저장소를 연결하고, 저장·조회 함수를 만든다.
5. 저장된 이전 달·이전 해 데이터를 조회해 전월 대비·전년 동월 대비 증감률을 계산하는 함수를 만든다.
6. 증감률이 ±10% 이상인 지표를 이상 징후로 판정하는 함수를 만든다.
7. 지표별 엑셀 파일을 여러 개 올릴 수 있는 업로드 화면을 만든다.
8. KPI 리포트 화면(표, 이상 징후 표시 포함)을 만든다.
9. 리포트를 PDF로 내보내는 기능을 만든다.
10. 업로드된 데이터를 근거로 답변하는 질의응답 챗봇 API(OpenAI 연동)를 만든다. (nice to have)
11. 챗봇과 대화할 수 있는 화면을 만든다. (nice to have)
12. Vercel에 배포하고, 환경변수(.env 값)를 Vercel 프로젝트에 등록한다.
